تنبيه اتصال قاعدة بيانات Firebase (Firestore)

تم رفض الوصول إلى Firestore. تأكد من تفعيل Firestore Database في مشروعك maps-9dcd4 وتحديث قواعد الأمان (Rules) لتسمح بالقراءة والكتابة على feedbacks و settings: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /feedbacks/{docId} { allow read, write: if true; }
    match /settings/{docId} { allow read, write: if true; }
  }
}
